## 📖 Sobre o Projeto
Este repositório reúne a estrutura digital completa desenvolvida para a escola de música **Musicalidade Consciente** e o lançamento do infoproduto **Violão Descomplicado: Da Teoria à Canção** (108 páginas e 19 capítulos ilustrados):

1. **Landing Page de Vendas (`index.html`):**
   - Arquitetura de conversão completa: Barra de escassez com cupom (`EBOOK`), Hero com VSL embutida, Dores do estudante de violão, Grade curricular dos 4 módulos / 19 capítulos, Seção de autoridade do autor (Fagner Santos), Oferta com cópia de cupom em 1 clique (`Clipboard API`), Garantia incondicional de 7 dias e FAQ interativo.
   - Integração direta com o checkout da **Eduzz** já aplicando automaticamente o cupom promocional via parâmetro de URL (`?cupom=EBOOK`).
2. **Página de Obrigado e Onboarding Pós-Venda (`obrigado.html`):**
   - Redirecionamento automático configurado na Eduzz para compras via PIX, Cartão e Boleto.
   - Vídeo tutorial pós-venda embutido + passo a passo visual em 3 etapas para o aluno acessar o PDF e EPUB no portal **Meu Eduzz / Nutror**.
3. **Produção Audiovisual com IA Generativa (Google Flow):**
   - Criação de vídeos promocionais e de suporte pós-venda mantendo consistência de personagens (avatares 2D com a camiseta oficial *Faguim Guittar*) e sincronia labial em português.
4. **Editoração, Identidade Visual e Documentação:**
   - Diagramação e publicação do Ebook em PDF e EPUB (108 páginas, mapas mentais, exercícios e dicionário de acordes), certificados oficiais de conclusão de módulos e materiais administrativos.

## 🛠️ Tecnologias e Ferramentas Utilizadas
- **Front-End:** HTML5 Semântico, CSS3 Moderno (Custom Properties, CSS Grid, Flexbox, Responsividade Mobile-First) e JavaScript (Vanilla ES6+).
- **Plataforma de Infoprodutos & Pagamentos:** Eduzz (Órbita / Nutror / Checkout Sun).
- **IA Generativa & Audiovisual:** Google Flow (geração de vídeo consistente *Frames to Video*), Reedsy / Calibre (editoração de PDF e EPUB).
- **Deploy & Hospedagem:** Netlify CDN.

## ⚙️ Como Executar Localmente
1. Clone este repositório:
   ```bash
   git clone https://github.com/tgojlima/projeto-musicalidade-consciente.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd projeto-musicalidade-consciente
   ```
3. Abra o arquivo `index.html` (Página de Vendas) ou `obrigado.html` (Página Pós-Venda) diretamente no navegador ou utilizando a extensão **Live Server** no VS Code.
